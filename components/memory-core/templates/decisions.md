# Decision record: {{PROJECT_NAME}}

Rulings, D-numbered, append-only. A ruling changes only through a new numbered decision that supersedes or amends it; the same change stamps the old entry with a one-line *Superseded by / Amended by DN* note under its heading and updates its index row. Those stamps are the only edits ever made to an old entry. An agent that finds reality contradicting a standing decision flags it in `open-questions.md` with a recommendation; only the maintainer retires a decision.

If multiple concurrent sessions write to this repo, only the gateway session assigns D-numbers; other lanes write `D-next` placeholders that the gateway resolves at merge.
