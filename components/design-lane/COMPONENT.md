- **Version:** 1.5.0

## What it installs

The design-system-as-law pattern for projects with a visual surface: one artifact is the visual source of truth for **built** design; approved-but-unimplemented design stages as proposals and converges into the source of truth when implemented. Ships the lane charter, the conventions checklist, the establishment + lifecycle procedure, and a starter sheet.

## Install notes

- Only for repos with a UI or visual output. Skip otherwise; do not install speculatively.
- The starter sheet carries a deliberately neutral placeholder palette, a theme toggle, the foundations sections (Color, Type, Iconography, Spacing, Shape and elevation, Motion, Layout and scroll, Voice & microcopy), a Status grammar placeholder, an Overlays behavior section, and one example component demonstrating the section pattern. It is a seed, not a finished system: the establishment procedure in the `design-proposals` skill (consolidate the first approved mocks into it, then sheet-first forever) is how it becomes real.
- The sheet ships **opinionated but swappable taste defaults** (D5): the type-sourcing law recommends Google Fonts, iconography recommends Material Symbols, and both are named as defaults the maintainer swaps at establishment, never as baked token values (the token block stays system-font neutral). Layout/scroll and overlay behavior are shipped as universal law, not a project pick.
- Product-specific visual law (what the accent hue means, the full voice rule list, state treatments) accumulates in the target's sheet and decisions; this component ships the categories and the discipline, never the values.
- **Two artifacts, one fact:** the sheet is the source of truth; `design.md` is its agent-readable derivation, generated by `scripts/generate_design_md.py` and never hand-edited. After filling placeholders at install, rerun the script so the two match. If ci-gates is installed, add `python scripts/generate_design_md.py --check` as an extra check (same pattern as `validate_rules.py`); in a Python-free repo, drop the script and design.md rather than hand-maintaining a copy.
