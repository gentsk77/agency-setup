# P10: Judges get fresh context and content-free dispatch

## Statement

Evaluation is performed by an agent in a fresh context that did not participate in producing the thing evaluated. The dispatch that spawns a judge contains only the artifact's location and the instruction to apply the rubric: no summaries, no framing, no producer commentary. A session that held the intake never grades it.

## Rationale

Context contaminates judgment. An agent that helped articulate an idea, or merely read an enthusiastic summary of it, anchors on that framing and grades the framing rather than the artifact. Fresh context is the agent equivalent of blind review, and it is nearly free: spawning a clean session costs seconds. Content-free dispatch is the hard part and the load-bearing part, because the natural instinct when dispatching is to "helpfully" summarize, which reintroduces the bias through the front door.

## What breaks without it

Self-graded work inflates: the producer-judge resolves every ambiguity in its own favor, honestly and invisibly. Revision loops stop converging because the judge and producer share the same blind spot. Independent verdicts (two judges agreeing) become meaningless when both read the same primed dispatch.
