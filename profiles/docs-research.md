# Profile: docs-research

For repos whose artifact is thinking: writing projects, research programs, strategy notebooks. Full memory discipline, no dev machinery.

## Component set

memory-core, claude-md-skeleton, gateway, steward.

## Follow-up questions

1. **What is the unit of output?** (an essay, a research stream, a synthesis doc) Name it in CLAUDE.md's repo map so sessions know where work accumulates versus where it is staged.
2. **Evidence discipline.** If the repo makes claims from sources, add an invariant to CLAUDE.md: sourced material is snapshotted immutably, synthesis evolves and cites (this is P09 applied to prose).
3. **Word budget.** Recommend 400 for `{{WORD_BUDGET}}`.

## First session after install

Braindump the project's driving question through the gateway. Expected output: the question decomposed in open-questions.md (⚖ items with recommendations), and a STATE.md that says what to read or write next.
